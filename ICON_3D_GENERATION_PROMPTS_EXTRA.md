# AplicoCV — 3D Icon Prompts (Batch 2: funnel & missing icons)

Second batch — the icons the `/comenzar` funnel and other spots needed that the first
set didn't cover (the funnel uses inline emoji, so it was missed). Same visual language
as batch 1 (glossy glass, brushed chrome and navy enamel, lit from the upper-left, brand
palette), each prompt **individually written**.

- **Unified path (this batch only — a SEPARATE folder):** `apps/web/public/icons/3d-extra/`
- **Filename = the icon's key, lowercase, `.png`** (e.g. `briefcase.png`).
- **Format:** PNG with real alpha (transparent). **Canvas:** 1024×1024.
- Every prompt: transparent background, **no border/card/frame**, object **fills ~92%** of
  the frame, one consistent camera/light, **no text**.

**Brand palette:** electric blue `#0A74F0`, sky/cyan `#1FBEF0`, deep navy `#0B1426`,
frosted white, brushed chrome; sparing violet-magenta `#7341FF` accent only where noted.
